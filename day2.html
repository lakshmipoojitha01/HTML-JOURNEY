1. WHAT IS HTML?

  • HTML stands for HyperText Markup Language.
  • It is used to create the structure of web pages.
  • It is a markup language, not a programming language.
  • HTML uses different tags to display content.

2. HYPERTEXT AND MARKUP

HyperText

  • Hypertext connects one page to another using links.
  • It helps users navigate between web pages.

Markup

  • Markup means using tags to structure content.
  • HTML tags tell the browser how to display content.

3. HISTORY OF HTML

HTML was created by Tim Berners-Lee in 1991 at CERN.

Year HTML Version Description
1991 HTML 1.0 Early version of HTML
1995 HTML 2.0 First standardized HTML version
1997 HTML 3.2 Added more HTML features
1999 HTML 4.01 Improved web page structure
2014 HTML5 Major HTML standard recommendation

4. HTML TAGS

Paired Tags

  • Paired tags have opening and closing tags.
  • Example:

<h1> Akkula Lakshmi Poojitha </h1>

Opening Tag: <h1>

Closing Tag: </h1>

Unpaired Tags

  • Unpaired tags do not need a closing tag.
  • Examples:

<br> - Line break

<hr> - Horizontal line

<img> - Image

5. BASIC HTML STRUCTURE

<!DOCTYPE html>
<html>
    <head>
        <title>My First Page</title>
    </head>

    <body>
        <h1>Hello, Welcome to HTML!</h1>
    </body>
</html>

Explanation:

  • <!DOCTYPE html> - Declares HTML5 document type.
  • <html> - Root element of the HTML document.
  • <head> - Contains page information.
  • <title> - Sets the browser tab title.
  • <body> - Contains visible page content.

6. HTML ELEMENT

An HTML element generally consists of an opening tag, content and a closing tag.

Example:

<h1> My Name is Poojitha </h1>

  • Opening Tag: <h1>
  • Content: My Name is Poojitha
  • Closing Tag: </h1>
