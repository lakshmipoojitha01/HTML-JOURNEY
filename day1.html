1. WHAT IS THE INTERNET?

The Internet is a global network that connects computers and devices around the world. It helps people share information, communicate and access different online services.

2. WHAT IS THE WEB?

The World Wide Web is a collection of websites and web pages that we access through the Internet. We use web browsers to explore the Web.

3. WHAT IS A WEB BROWSER?

A Web Browser is software used to access and view websites and web pages.

Examples:

  • Google Chrome
  • Microsoft Edge
  • Mozilla Firefox
  • Safari

4. WHAT IS A WEB PAGE?

A Web Page is a single document on the Web. It can contain text, images, videos, audio and hyperlinks. Every web page has a URL.

5. WHAT IS A WEBSITE?

A Website is a collection of related web pages available under a common domain name.

Examples of Website Pages:

  • Home Page
  • About Page
  • Services Page
  • Contact Page
  • Portfolio Page

6. WHAT IS A WEB APPLICATION?

A Web Application is an application that runs through a web browser and allows users to perform different tasks.

Examples:

  • Gmail - Sending and receiving emails
  • Google Docs - Creating documents
  • Amazon - Online shopping
  • GitHub - Managing coding projects
  • LinkedIn - Professional networking
